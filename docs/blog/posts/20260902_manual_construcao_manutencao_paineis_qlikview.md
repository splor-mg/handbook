# Referências para trabalhar com Qlikview

Os conhecimentos necessários para criar, alterar e dar manutenção em painéis QlikView estão distribuídos entre diferentes gravações, demonstrações e materiais utilizados pela equipe.

Este post reúne as principais referências relacionadas ao QlikView que foram compartilhadas ao longo das atividades da SPLOR, servindo como um ponto de partida para consulta. A ideia é facilitar a localização dos materiais sem substituir o conteúdo original de cada treinamento.

<!-- more -->

## Por onde começar

Para quem ainda não trabalhou com Qlikview ou quer retomar os conceitos básicos, a melhor referência é o material do **Webnar Inteligência.MG #2**.

Ele apresenta a ferramenta desde os primeiros passos e passa por assuntos como carregamento e transformação de dados, modelagem, construção do painel e recursos utilizados no desenvolvimento.

[Webnar Inteligência.MG #2 - Qlikview](https://splor-mg.github.io/handbook/blog/webnar-intelig%C3%AAnciamg-2---qlikview/){ .md-button }


## Construção de menus e interações

O Qlikview permite criar comportamentos diferentes para os objetos de um painel a partir de variáveis e expressões.

O material sobre **menu de agregação de valores dinâmico** mostra uma aplicação prática dessa ideia. A demonstração pode ser útil principalmente quando houver necessidade de permitir que o usuário escolha, de forma interativa, o tipo de informação apresentado em uma tabela ou relatório.

[Qlikview - Menu de agregação de valores dinâmico](https://splor-mg.github.io/handbook/blog/-qlikview---menu-de-agrega%C3%A7%C3%A3o-de-valores-din%C3%A2mico/){ .md-button }


## Manutenção do Relatório Operacional

Além da construção dos painéis, existe uma referência específica para a rotina de manutenção do **Relatório Operacional** no ambiente utilizado pela equipe.

O material aborda o acesso ao servidor, a atualização do painel e a relação entre o arquivo Qlikview e as bases que fornecem os dados utilizados no relatório. Também registra procedimentos e pontos de atenção para situações em que a atualização automática não ocorre como esperado.

[Live Code - Manutenção do Relatório Operacional](https://splor-mg.github.io/handbook/blog/live-code/){ .md-button }


## Instaladores

Os instaladores do Qlikview estão disponíveis no espaço compartilhado da equipe.

Para utilização em uma máquina local, deve ser considerada a versão **Desktop para Windows**. Os demais arquivos ficam disponíveis para situações específicas, como uma eventual reinstalação no servidor.

[Instaladores do Qlikview](https://cecad365.sharepoint.com/sites/Splor/Documentos%20Compartilhados/Forms/AllItems.aspx?id=%2Fsites%2FSplor%2FDocumentos%20Compartilhados%2FGeneral%2F%40aid%2Fqlikview%5Finstaladores&viewid=18ff56ea%2D4741%2D4a03%2D9d7e%2D2f87751ef241){ .md-button }


## Materiais relacionados

As referências acima não precisam ser consultadas de forma isolada. Dependendo da atividade, pode ser útil combinar os materiais:

- **Primeiro contato com a ferramenta:** Webnar Inteligência.MG #2.
- **Construção de interações no painel:** menu de agregação de valores dinâmico.
- **Rotina de manutenção:** Live Code do Relatório Operacional.
- **Instalação:** arquivos disponibilizados no SharePoint.

Dessa forma, os materiais funcionam como uma pequena trilha de consulta para diferentes necessidades relacionadas ao Qlikview.
